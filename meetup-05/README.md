## HTTP Deep Dive
By André Luyer, Sr. Performance Consultant, Rabobank
In the past HTTP was just used for websites. Today many applications depend on APIs, using HTTP(S) as communication protocol as well. So, when troubleshooting there is a big change that you have to investigate HTTP traffic. With HTTP/2 and HTTP/3 becoming more popular that may require a different approach.
This session is not only about how to use Wireshark, but especially about understanding the protocol.

*Bio: André is a senior Performance Consultant and troubleshooter at Rabobank and has been analyzing packets for over 30 years. He started his career as a troubleshooter for network issues, both hard- and software, and later specialized in performance testing, which requires a combination of in-depth knowledge of networking protocols and coding skills

## Wireshark in critical infrastructure - 5W's
By Japser Rappard, Legian
Critical infrastructures, Operational Technology/ Industrial Control Systems are more and more converged. Defensible Network architecture is typically done with IT Cyber security in mind. This session gives insight in 5W's on utilizing Wireshark in securely defining, converging and operating critical infrastructures.

*Bio: Jasper is a seasoned infrastructure engineer and security consultant at Legian. With over 25 years hands-on experience his key driver is curiosity as he finds every single environment has its own quirks.
